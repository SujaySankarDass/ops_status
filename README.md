# OpsStatus

OpsStatus is a production-style service status application for a fictional SaaS company.

Engineers can update the health of services, while customers can view a clean public status page.

---

## Technologies

- Java
- Spring Boot
- PostgreSQL
- Docker
- GitHub Actions
- AWS
- Terraform
- Prometheus
- Grafana

---

## Architecture

Client
↓
Spring Boot API
↓
PostgreSQL Database
